# JGGL Songs: лендинги под гипотезы

Статический сайт без зависимостей, в том же визуальном стиле, что `trends-web`, но с крупным шрифтом (18 px) для аудитории 35–70.

```bash
POSTHOG_KEY=phc_... npm run build   # сборка в dist/ (без ключа события идут только в консоль)
npm start                            # http://127.0.0.1:4174/
npm run icons                        # пересобрать иконки вкладки из public/favicon.svg (нужен ImageMagick)
```

Зависимостей нет, `npm install` не нужен.

## Деплой на Vercel

Репозиторий готов к авто-деплою: `vercel.json` задаёт сборку `node build.cjs` и папку `dist`.

1. Vercel → Add New → Project → выбрать этот репозиторий. Настройки менять не надо (Framework: Other).
2. Environment Variables: `POSTHOG_KEY` (обязательно для аналитики и сохранения e-mail), при необходимости `POSTHOG_HOST`.
3. Каждый push в `main` деплоится в прод, остальные ветки и PR получают превью-ссылки.

На Vercel внутренняя страница со списком гипотез не собирается (`BUILD_HUB=1` включает её, но корневой редирект `/` → `/your-voice/` из `vercel.json` её закроет). Все страницы отдаются с `noindex`.

Иконки вкладки: `public/favicon.svg` (логотип JGGL на тёмной плитке), `favicon.ico`, PNG 32/180/192/512 и `site.webmanifest`; всё из `public/` копируется в корень сайта.

## Страницы (гипотезы)

| Адрес | Гипотеза | Режим hero |
|---|---|---|
| `/your-voice/` | Есть слова или повод, хочу услышать готовую песню своим голосом | вставить куплет |
| `/memory-melody/` | Нужна мелодия под видео воспоминаний или поздравление | выбор настроения |
| `/finish-my-song/` | Написал слова, но не умею аранжировать и сводить | выбор стиля |
| `/worship-songs/` | Хочу песню на свой псалом, при этом вера остаётся моей | кнопка |
| `/gift-song/` | Нужен подарок на юбилей, годовщину, благодарность | выбор повода |

Тексты гипотез, аудитория и метрика лежат в `src/experiments.cjs`. Новая гипотеза — новый объект в массиве и повторная сборка. Общие тексты — `src/content.cjs`.

## Язык

Переключатель EN/RU стоит в шапке рядом с кнопкой. Чтобы оставить только английский, поставь `languages: ['en']` в `config.cjs` и пересобери: переключатель и русские строки исчезнут из страниц.

## События (PostHog)

`landing_view`, `hero_cta_click`, `lyrics_paste` (только число символов), `style_select`, `filter_select`, `song_open`, `sample_play`, `make_like_this_click`, `faq_open`, `scroll_50`, `scroll_90`, `lang_switch`, `header_cta_click`, `final_cta_click`. К каждому добавляются `experiment`, `lang` и входящие `utm_*`.

## Ссылка в приложение

Входящие `utm_*` передаются в `web.jggl.ai`. Недостающие заполняются: `utm_source=songs-lp`, `utm_medium=landing`, `utm_campaign=<slug страницы>`, `utm_content=<место кнопки>`, `utm_term=<выбранный стиль/повод/жанр>`. Рекламные идентификаторы (fbclid и т. п.) не передаются. Текст куплета в ссылку не попадает: он копируется в буфер обмена.

## Что ещё заглушка

- Песни-примеры: звук синтезируется в браузере (`prof` в `src/app.js`). Настоящие файлы подключаются полем `audio` в `src/content.cjs` (пока не реализовано в плеере).
- Список утверждений о продукте, которые нужно подтвердить до платного трафика: `CLAIMS.md`.
- `buildHub: true` собирает внутреннюю страницу со списком гипотез. Перед публичным деплоем выключить.
